# Google Region Monitor — Chrome extension v1.9.4

Расширение собирает результаты Google Search по готовым страновым профилям и сохраняет их в удобный HTML-отчёт.

**Главное: вам почти не нужно настраивать профили.** В расширение уже включены 19 подготовленных профилей стран: с регионом поиска, языками Google и готовыми поисковыми запросами. Каталог стандартных профилей автоматически обновляется из GitHub. Для обычного старта достаточно выбрать страну, ввести API-ключ 2Captcha и выбрать режим **2Captcha Scrape**, если приоритет — максимально полный постраничный сбор.

---

## Быстрый старт

1. Установите расширение по инструкции ниже и откройте его боковую панель.
2. Перейдите на вкладку **«Мониторинг»**, выберите источник **«2Captcha Scrape (HTML каждой страницы)»**, введите API-ключ 2Captcha и нажмите **«Сохранить API-ключ»**.
3. Выберите профиль страны, отметьте нужные запросы и нажмите **«Сформировать отчёт»**.

Остальные параметры уже имеют рабочие значения. Для первого пробного запуска оставьте период **«За последние 24 часа»** и глубину **3 страницы на запрос**. После проверки можно увеличить глубину до 5 или 10 страниц.

> API-ключ нужен только для двух режимов 2Captcha. В режиме «Обычный режим — мой браузер» ключ не требуется, но поиск выполняется непосредственно в вашем Chrome и может чаще сталкиваться с ограничениями Google.

## Установка в Google Chrome

Расширение распространяется как ZIP с исходной папкой Chrome Extension. Это не установочный файл `.crx`: расширение загружается в Chrome в режиме разработчика.

1. Скачайте ZIP из раздела **Releases** репозитория:  
   https://github.com/artemmalkin/Google-Region-Monitor/releases
2. Распакуйте ZIP в постоянную папку, например `Документы/Google-Region-Monitor`.
3. Откройте в Chrome адрес `chrome://extensions`.
4. Включите переключатель **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное»**.
6. Выберите распакованную папку, внутри которой непосредственно находится файл `manifest.json`.
7. Закрепите значок расширения на панели Chrome через меню расширений, чтобы быстро открывать боковую панель.

Минимальная версия Chrome, указанная в расширении, — **116**.

### Как обновить уже установленную распакованную версию

Чтобы сохранить локальные профили и API-ключ, не удаляйте старое расширение без необходимости:

1. Распакуйте новый ZIP.
2. Скопируйте новые файлы поверх файлов прежней папки расширения, подтвердив замену.
3. Откройте `chrome://extensions` и нажмите кнопку **«Обновить»** на карточке Google Region Monitor.

Старайтесь сохранять прежнюю папку установки. При удалении расширения или создании новой установки Chrome может создать для него другое локальное хранилище. Для штатного автоматического обновления самой программы потребуется публикация в Chrome Web Store; GitHub Release позволяет скачать и вручную заменить распакованную сборку.

## Профили уже подготовлены — настраивать их с нуля не нужно

В комплект входит **19 стандартных профилей**. Встроенный каталог в этой сборке соответствует файлу, обновлённому **26 ноября 2026 года**. В них уже заданы:

- страна, для которой формируется Google-выдача;
- язык страницы Google;
- языки результатов поиска, если для профиля предусмотрено ограничение;
- готовые поисковые запросы;
- тематические группы этих запросов.

Стандартные профили сгруппированы по регионам: Латинская Америка, Южная Азия, Восточная и Юго-Восточная Азия. Полный каталог доступен сразу после установки — даже если интернет или GitHub временно недоступны. В профилях Вьетнама, Индонезии и Китая дополнительно подготовлено по четыре тематические группы: проекты «Росатома», конкуренты, энергетическая сфера и общественно-политическая сфера. Их можно выбирать отдельно — вручную создавать эти группы не требуется.

### Как работает автоматическая синхронизация

Стандартный каталог встроен в архив расширения и дополнительно загружается из GitHub:

- при установке/обновлении и запуске браузера расширение пытается получить актуальный каталог;
- далее каталог автоматически проверяется примерно раз в сутки;
- для ручной проверки откройте раздел **«Стандартные профили из GitHub»** и нажмите **«Проверить обновление»** — эта кнопка также проверяет наличие нового GitHub Release;
- если доступна новая версия программы, станет доступна кнопка **«Скачать обновление»**. После загрузки ZIP его нужно распаковать, заменить файлы прежней папки и перезагрузить расширение на `chrome://extensions`;
- если сеть или GitHub недоступны, остаётся последний сохранённый каталог; при первой установке есть встроенный набор профилей.

**Для обычного пользователя никаких GitHub-настроек и GitHub-токенов не требуется.** Не нужно вручную скачивать JSON, копировать коды стран или создавать поисковые строки.

Важно различать два вида данных:

- **Стандартный каталог** синхронизируется из общего GitHub-репозитория автоматически.
- **Ваши личные изменения и пользовательские профили** сохраняются локально в хранилище Chrome. Они не публикуются в общий каталог и автоматически не переносятся на другой компьютер. Для переноса используйте кнопки **«Экспорт профиля»** и **«Импорт из файла»**.

### Как выбрать профиль

1. Откройте вкладку **«Профили»**.
2. Выберите нужную страну в списке. Профили в списках сгруппированы по регионам.
3. Перейдите на вкладку **«Мониторинг»** и убедитесь, что выбран тот же профиль в поле **«Профиль региона»**.

На этом настройка профиля закончена. При запуске расширение само передаёт страну и языки в адрес Google Search. Оно **не меняет настройки Google-аккаунта и не требует открывать Google Preferences**.

Три параметра профиля влияют на выдачу:

| Параметр | Что означает |
|---|---|
| Страна поиска (`gl`) | Страна, для которой Google должен формировать выдачу |
| Язык интерфейса (`hl`) | Язык страницы поиска Google |
| Языки результатов (`lr`) | Ограничение языка документов в результатах; если список пуст, языкового ограничения нет |

### Нужно ли редактировать профиль?

Нет — для первого запуска не нужно.

В редакторе можно менять название профиля, назначать профили в собственные группы и редактировать группы поисковых запросов. Это дополнительные возможности, а не обязательный этап настройки.

Если вы измените язык, страну или поисковые запросы стандартного профиля и нажмёте обычную кнопку **«Сохранить профиль»**, расширение сохранит вашу версию как отдельный локальный пользовательский профиль. Стандартная запись останется нетронутой. Общие стандартные профили может изменять только сопровождающий репозитория — через GitHub Fine-grained token с правами записи. Обычным пользователям этот токен не нужен.

## Два обязательных выбора для рекомендуемого запуска

### 1. Введите API-ключ 2Captcha

Для рекомендуемого режима Scrape нужен аккаунт 2Captcha и API-ключ, который даёт доступ к Scraper API.

1. Войдите в свой аккаунт 2Captcha и скопируйте API-ключ из настроек аккаунта.
2. В расширении откройте **«Мониторинг»**.
3. В поле **«Источник поисковой выдачи»** выберите **«2Captcha Scrape (HTML каждой страницы)»**.
4. В появившемся блоке вставьте ключ в поле **«API-ключ 2Captcha»**.
5. Нажмите **«Сохранить API-ключ»**.

Ключ хранится локально в Chrome Storage на этом браузерном профиле. Он не записывается в файлы расширения, GitHub или диагностический лог. Не отправляйте его другим людям и не вставляйте в README, скриншоты или публичные сообщения.

**Не путайте два токена:**

- **API-ключ 2Captcha** нужен для платного сбора поисковой выдачи через 2Captcha.
- **GitHub Fine-grained token** нужен только разработчику, который публикует изменения стандартного каталога. Для работы расширения он не нужен.

Официальные страницы 2Captcha:

- тарифы Scraper API: https://2captcha.com/scraper/scraper-api
- руководство по API на русском: https://2captcha.com/ru/scraper/scraper-api/api

### 2. Выберите режим Scrape для максимального постраничного сбора

В списке **«Источник поисковой выдачи»** доступны три режима:

| Режим | Как работает | Когда выбирать |
|---|---|---|
| **Обычный режим — мой браузер** | Открывает Google в вашем Chrome и последовательно читает страницы | Для бесплатного пробного запуска без API-ключа; зависит от ограничений Google и браузера |
| **2Captcha Google Search API** | Получает структурированные результаты Google; выбранное число страниц передаётся одним API-заданием на запрос | Когда важнее экономить число API-заданий |
| **2Captcha Scrape (HTML каждой страницы)** | Получает HTML каждой страницы Google отдельным API-заданием и разбирает его внутри расширения | **Рекомендуемый режим, когда приоритет — максимально полный сбор по нескольким страницам** |

В Scrape расширение получает исходный HTML каждой страницы, а затем извлекает из него заголовки, ссылки и описания. Такой способ даёт расширению больше исходных данных страницы, чем работа только со структурированными полями API. Это рекомендуемый вариант для наиболее тщательного постраничного мониторинга.

Это не гарантия, что Google всегда покажет одинаковое количество ссылок: состав выдачи зависит от Google, страны, периода, запроса и доступности страниц. При CAPTCHA, ограничении автоматических запросов или ответах HTTP 403/429 расширение прекращает дальнейший сбор, а уже полученные результаты сохраняет в отчёте.

## Стоимость: какой режим расходует больше

Режимы 2Captcha расходуют баланс по-разному. Самая важная разница — **сколько API-заданий создаётся**.

- В **Scrape** каждую страницу каждого выбранного запроса расширение получает отдельным заданием.
- В **Google Search API** для каждого выбранного запроса создаётся одно задание. В него можно включить сбор до 10 страниц.
- В **обычном режиме браузера** задания 2Captcha не создаются и баланс 2Captcha не расходуется.

### Пример

Допустим, вы отметили 6 поисковых запросов и выбрали 3 страницы на запрос:

| Режим | Максимум заданий на такой запуск |
|---|---:|
| 2Captcha Scrape | 6 запросов × 3 страницы = **18 заданий** |
| 2Captcha Google Search API | 6 запросов × 1 задание = **6 заданий** |
| Обычный режим — мой браузер | **0 заданий 2Captcha** |

При 10 страницах Scrape создаст до 10 заданий на каждый выбранный запрос. Поэтому увеличение глубины поиска и количества отмеченных запросов заметно увеличивает расход. Scrape обычно обходится дороже именно из-за большего количества отдельных заданий; точную сумму определяет действующий тариф и фактическая история вашего аккаунта.

### Как контролировать расходы

1. Введите API-ключ и выберите нужный метод.
2. Откройте блок статистики 2Captcha и нажмите **«Обновить статистику»**.
3. Расширение запросит баланс и историю заданий обоих методов.
4. Поле **«Средняя стоимость задания выбранного метода»** показывает среднее по последним доступным успешным заданиям этого метода.
5. После отчёта нажмите **«Обновить статистику»** ещё раз: поле **«Последний отчёт»** покажет стоимость, когда история 2Captcha вернёт данные по всем заданиям отчёта.

Статистика не запрашивается автоматически. Проверка баланса и истории не запускает новый поиск Google. Сумма последнего отчёта не угадывается: пока история не подтвердила стоимость всех его заданий, поле может оставаться пустым.

**Практический совет:** сначала выполните короткий пробный запуск — один профиль, 1–2 запроса, 2–3 страницы. Посмотрите результат и фактическую стоимость в истории. Затем увеличивайте количество запросов или страниц.

## Как сформировать отчёт

1. Откройте вкладку **«Мониторинг»**.
2. Выберите профиль страны.
3. В списке **«Запросы для отчёта»** отметьте нужные поисковые строки. Кнопка **«Все»** отмечает все запросы профиля, **«Снять»** снимает отметки.
4. Установите период поиска.
5. Выберите максимальное число страниц на запрос.
6. Нажмите **«Сформировать отчёт»**.

### Период поиска

Можно выбрать результаты за последний час, последние 24 часа, неделю, месяц, год или за всё время. По умолчанию выбран период **«За последние 24 часа»**.

### Количество страниц

Можно выбрать 1, 2, 3, 5 или 10 страниц на каждый запрос. По умолчанию — 3 страницы.

- 1 страница — самый короткий и экономный тест;
- 3 страницы — разумный стартовый вариант;
- 5 или 10 страниц — более глубокий сбор, но в Scrape он требует пропорционально больше API-заданий.

### Что делает параметр `filter=0`

В обычном браузерном режиме и Scrape расширение передаёт Google параметр `filter=0`, который просит не исключать часть похожих результатов. Он сохраняется и при переходах между страницами. Режим Google Search API этот параметр не использует.

### Минимальный интервал между запросами

Поле **«Минимальный интервал между запросами Google»** относится к обычному режиму браузера. По умолчанию установлено 2 секунды. Не ставьте 0 без необходимости: более частые обращения могут повысить вероятность ограничений со стороны Google. В двух режимах 2Captcha это поле не управляет скоростью заданий API.

### Что происходит после запуска

- Расширение последовательно обрабатывает отмеченные запросы и страницы.
- В Scrape одна страница — одно задание; задания выполняются последовательно.
- Если Google вернул страницу CAPTCHA или ограничение доступа, расширение прекращает дальнейшие запросы и сохраняет уже собранное.
- Кнопка **«Остановить»** прекращает дальнейший сбор. В отчёт попадут уже обработанные данные; если задание 2Captcha ещё ожидало результата, оно может не успеть попасть в отчёт.
- По окончании автоматически скачивается HTML-файл отчёта `google-report-....html`. Откройте его в Chrome или другом браузере. В нём есть профиль, параметры поиска, запросы, страницы, заголовки, ссылки и описания найденных результатов.

### Прямые ссылки на сайты

Расширение старается получить прямой адрес статьи из ответа 2Captcha или HTML Google до обращения к перенаправлению Google `/goto`. Если прямой адрес не найден, используется резервное разрешение ссылки Google. Когда точный адрес получить не удалось, ссылка остаётся в отчёте; домен, показанный Google, может выводиться отдельно как подсказка, а не как подтверждённый адрес статьи.

## Дополнительная проверка СМИ через ChatGPT

В разделе мониторинга есть флажок **«Проверять региональную принадлежность СМИ через ChatGPT перед созданием отчёта»**. Он включён по умолчанию.

При включённой настройке расширение открывает веб-версию ChatGPT и просит проверить, относится ли источник публикации к выбранному региону. Для работы нужна активная авторизация на https://chatgpt.com/. Отдельный OpenAI API-ключ не требуется: используется ваша открытая веб-сессия ChatGPT.

- Проверка выполняется после сбора Google и до создания HTML-отчёта.
- Ссылки, которые ChatGPT исключил, не удаляются бесследно: в отчёте их можно посмотреть в раскрываемом разделе **«Показать скрытые результаты ChatGPT»** вместе с объяснением.
- Если ChatGPT не ответил или проверка завершилась ошибкой, найденные ссылки остаются в основном отчёте.
- Чтобы включить все результаты без этой дополнительной проверки или сократить время подготовки отчёта, снимите флажок.

Опция **«Автоматически настраивать режим размышления ChatGPT»** дополнительная и по умолчанию выключена. Для обычной работы её включать не нужно.

## Статистика и диагностический лог 2Captcha

В блоке 2Captcha доступны баланс, примерная оценка количества оставшихся заданий, средняя стоимость задания выбранного метода и стоимость последнего отчёта.

Кнопка **«Обновить статистику»** обращается к балансу и истории заданий только после нажатия. При расчёте используются завершённые задания и фактические цены из истории. Если история ещё не содержит все задания последнего отчёта, стоимость не показывается до следующего обновления.

После запуска через 2Captcha может появиться кнопка **«Скачать лог запросов и ответов 2Captcha»**. Она скачивает уже собранные диагностические данные и не создаёт новый поиск. API-ключ и заголовок Authorization маскируются, но лог может содержать ваши поисковые запросы, URL и фрагменты ответов. Просмотрите файл перед отправкой кому-либо или публикацией в открытом доступе.

## Что важно знать

- Расширение не меняет настройки Google-аккаунта: страна и языки задаются в профиле и передаются в ссылке каждого поиска.
- Не нужно настраивать профили, если вас устраивает один из готовых страновых наборов.
- Стандартные профили обновляются из GitHub автоматически; GitHub-токен для этого не нужен.
- Личные пользовательские профили и API-ключ хранятся локально в Chrome. Для другого компьютера используйте экспорт/импорт профилей и введите API-ключ заново.
- API-ключ 2Captcha — секретный. Не публикуйте его.
- CAPTCHA и ограничения Google могут остановить сбор; расширение сохраняет уже собранные результаты, а не обещает обход любых защит.
- Число найденных страниц и ссылок не гарантировано: выдача Google меняется со временем и зависит от профиля, запроса и выбранного периода.

## Если что-то пошло не так

| Проблема | Что проверить |
|---|---|
| Не запускается режим 2Captcha | Выбран режим 2Captcha, ключ введён и сохранён, в аккаунте есть баланс и доступ к Scraper API |
| Профили не обновились | Проверьте интернет и нажмите **«Проверить обновление»**; встроенный каталог остаётся доступен |
| Отчёт содержит меньше страниц, чем выбрано | Посмотрите журнал запуска: Google мог вернуть CAPTCHA/ограничение, ошибку или не вернуть запрошенную страницу |
| ChatGPT-фильтр не завершился | Проверьте, что вы вошли в https://chatgpt.com/; при ошибке ссылки сохраняются в отчёте без фильтрации |
| Нужно перенести профиль на другой компьютер | Используйте **«Экспорт профиля»** на старом устройстве и **«Импорт из файла»** на новом |

---

### Локальная проверка

Требуется Node.js 18 или новее:

```bash
node --check sidepanel.js
node --check background.js
node --test tests/*.test.js
```

В релизной сборке включены автоматические тесты логики профилей, 2Captcha Scrape / Google Search API, пагинации, прямых ссылок и диагностики.
