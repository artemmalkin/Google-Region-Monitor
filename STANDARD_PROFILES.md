# Стандартные профили: конфигурация GitHub

По умолчанию расширение читает:

`https://raw.githubusercontent.com/artemmalkin/Google-Region-Monitor/master/config/standard-profiles.json`

## Формат файла

```json
{
  "schemaVersion": 1,
  "updatedAt": "2026-11-19T00:00:00.000Z",
  "profiles": [
    {
      "id": "vietnam",
      "name": "Вьетнам",
      "interfaceLang": "vi",
      "resultLangs": "vi, en",
      "region": "VN",
      "queries": ["rosatom", "\"rosatom\" AND \"rooppur\""]
    },
    {
      "id": "indonesia",
      "name": "Индонезия",
      "interfaceLang": "id",
      "resultLangs": "id, en",
      "region": "ID",
      "queries": ["rosatom"]
    }
  ]
}
```

### Обязательные и дополнительные поля

| Поле | Формат | Описание |
|---|---|---|
| `id` | Строка, 1–80 символов | Уникальный постоянный ID. Допустимы латинские буквы, цифры, `_`, `-`, `.` |
| `name` | Строка | Отображаемое название профиля |
| `interfaceLang` | Строка | Код языка интерфейса Google для `hl` |
| `resultLangs` | Строка или массив строк | Языки фильтра `lr`, например `"id, en"` или `["id", "en"]` |
| `region` | Строка | Код страны для `gl`, например `ID`, `VN`, `BD` |
| `queries` | Массив строк | Запросы, каждый элемент — отдельный запрос Google |

В `profiles` можно добавить до 500 записей. Все `id` должны быть уникальны.

## Что произойдёт при обновлении

Успешная синхронизация заменяет локальный кеш стандартных профилей версией из GitHub. Пользовательские профили хранятся отдельно и не удаляются. Если пользователь изменил стандартный профиль и нажал обычную кнопку «Сохранить профиль», приложение создаёт локальную копию с новым пользовательским ID. Для изменения исходной стандартной записи используйте отдельную кнопку отправки изменений в GitHub; это обновит общий JSON и распространит изменение другим пользователям. Кнопка удаления рядом с выбором стандартного профиля удаляет исходную запись из GitHub после подтверждения.

Если в GitHub будет ошибка сети, HTTP 404 или JSON не пройдёт проверку, расширение оставит прежний кеш стандартных профилей.


## Изменение списка из расширения (v1.4.0)

При наличии Fine-grained token с правом `Contents: Read and write` расширение может добавить локальный профиль, обновить выбранный стандартный профиль по его `id` или удалить стандартный профиль. Каждая операция меняет `config/standard-profiles.json` через GitHub Contents API и создаёт commit. После записи список повторно загружается в расширение. Удаление стандартной записи влияет на всех пользователей этого стандартного набора при их следующей синхронизации.


## Совместимость Preferences (v1.4.1)

Чтение и изменение настроек Google Preferences выполняется по структурным атрибутам (`data-pid`, `data-value`, `data-alllangmap`, `aria-selected`, `aria-checked`) и не зависит от локализованных подписей интерфейса.
